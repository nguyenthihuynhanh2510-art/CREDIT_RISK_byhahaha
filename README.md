# SmartCredit AI - Cổng Thông Tin Chấm Điểm & Quản Trị Rủi Ro Tín Dụng

Hệ thống thẩm định và ra quyết định cấp tín dụng bán lẻ tự động tuân thủ chuẩn mực **Basel II Trụ cột 1 & 2**, **IFRS 9**, và quy đổi sang **Thẻ điểm FICO Scorecard**.

## Các Tính Năng Nổi Bật:
1. **Thẩm định Tức thì (Single STP Scoring):** Đồng hồ đo điểm FICO, phân hạng rủi ro, dự kiến lãi/lỗ (+/- VND) và giải trình logic IF-THEN minh bạch từ Cây quyết định.
2. **Chấm điểm Danh mục Lô (Batch Excel):** Chấm hàng nghìn hồ sơ từ file Excel/CSV, phân tích phân bổ rủi ro toàn chi nhánh.
3. **Trung tâm Điều hành Chính sách (CRO Policy Center):** Tinh chỉnh tham số kinh tế vi mô (lãi suất $, chi phí vận hành $, tỷ lệ tổn thất $), quan sát đường cong lợi nhuận.
4. **Báo cáo Kiểm toán Basel II:** Giám sát chỉ số trôi dạt dân số  = 0.00013$, AUC = 0.8521, Gini = 0.7041, KS = 55.87%.
